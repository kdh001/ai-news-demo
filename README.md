# ai-news — 오프라인 다이제스트 데모

여러 출처의 AI 뉴스와 연구 자료를 수집해 한국어 다이제스트로 정리하던 개인 프로젝트에서 일부 처리 코드를 선별한 데모입니다. **제공된 데이터와 요약 응답은 합성 예제**이며, 네트워크나 API 키 없이 실행됩니다.

## 구현한 흐름

1. 합성 Hacker News 응답에서 원본의 AI 키워드 필터와 `Item` 스키마를 이용해 항목을 정규화합니다.
2. 모든 합성 항목에 KST 날짜 범위를 적용합니다. 범위는 시작일과 종료일을 포함하며 시각이 없는 항목은 제외합니다.
3. 합성 요약 응답을 만든 다음 원본의 마크다운 추출과 이를 보완한 Obsidian 블록 ID 삽입 로직을 실행합니다.
4. URL 또는 `objectID`가 중복된 항목은 첫 항목만 유지하고, 지정한 출력 파일이 이미 있으면 기존 파일을 보존합니다. 식별자가 모두 없는 항목은 중복 제거하지 않습니다.

## 실행

Python 3.10 이상이면 별도 패키지 설치 없이 실행할 수 있습니다.

```bash
python3 ai_news.py --from 2026-01-01 --to 2026-01-02 --output digest-demo.md
python3 -m unittest discover -s tests -v
```

`--input 다른파일.json`으로 Hacker News 응답 형식의 JSON을 지정할 수 있습니다. 각 `hits` 항목의 `created_at_i`는 Unix 초 단위 시각입니다. 기간 내 제목은 빈 문자열·제어문자·백틱을 허용하지 않으며 점수와 댓글 수는 0 이상의 정수여야 합니다. 점수나 댓글 수가 없거나 null이면 0으로 처리합니다. 시각이 없거나 숫자가 아닌 항목은 제외합니다. 출력 폴더는 미리 만들어야 합니다. 동일한 출력을 다시 만들 때는 다른 파일명을 지정하세요.

## 원래 프로젝트와의 차이

원래 프로젝트에는 Hacker News·Reddit·RSS·arXiv·Hugging Face 수집과 Cursor SDK를 통한 요약 기능이 있었습니다. 이 데모는 외부 수집 및 SDK 실행 경계를 합성 데이터와 고정된 출력으로 대체합니다. Reddit 등 다른 출처 수집, 실제 AI 요약, 웹 검색, 자동 스케줄링, 볼트 동기화 및 Git 자동 전송은 포함하지 않습니다. 합성 응답은 사실 확인이나 요약 품질 검증을 대신하지 않습니다. 원본 키워드 필터는 부분 문자열을 검사하므로 예를 들어 `chair`도 `ai`에 일치하는 오탐이 생길 수 있습니다.

`news_core.py`에는 원본의 항목 스키마, 키워드 필터, 마크다운 추출과 블록 ID 처리 코드가 포함돼 있습니다. 입력 검증·기간 필터·중복 제거, 기존 블록 ID 보존과 합성 응답 실행 코드는 이 사본에서 보완했습니다. 블록 ID는 제목 바로 뒤의 빈 줄을 건너뛰고 이어지는 ID를 재사용합니다. 기존에 중복된 ID는 자동으로 고치지 않습니다.

이 프로젝트의 원래 뉴스 요약에는 Cursor SDK 기반 AI 에이전트를 사용하도록 구현돼 있으며, 개발에도 AI의 도움을 받았습니다.

## 라이선스와 자료

프로젝트의 배포 라이선스는 아직 정해지지 않았습니다. 기존 뉴스 다이제스트, 기사 원문과 논문은 이 사본에 포함하지 않았습니다.
